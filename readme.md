# Personal Portfolio Website (CSS Core)

Web Dev I – Lab Assignment 2. A one-page portfolio styled with an external stylesheet.

## Project Structure
```
portfolio-project/
├── index.html
├── style.css
├── README.md
└── images/
    └── profile.svg
```

## Features
- External CSS (`style.css`) linked in `<head>`
- Colour theme with CSS variables (blue `#0047ab`, grey `#f4f4f4`, dark text `#222`)
- Poppins font via Google Fonts
- Sticky header and styled navigation with hover effects
- Box model spacing, `<hr>` separators, image shadow
- Skills table with alternating row colours
- Contact form with labels, placeholders and validation (`required`, `minlength`, `type="email"`)
- Fixed "Back to Top" button, smooth scrolling
- Responsive layout for small screens

## How to Run
Open `index.html` in any browser.
